# Contributing

**Creative Quality Of Life** (`qolminecraft`, store slug `creative-qol`) is a **closed-source** project.

- **Public docs** (README, changelog, license, icon): [QoL-minecraft-public](https://github.com/alanjmrt94/QoL-minecraft-public)
- **Development source** lives in a **private** GitHub repo. It is not open for code pull requests.
- In the private clone, those docs are edited at the repo root and synced into the `public-docs/` submodule. Do not `git push` the private tree to the public remote.
- Community chat: [discord.gg/CcUNTJjPD](https://discord.gg/CcUNTJjPD)
- Issues on the **public** docs repo are welcome for README / changelog / license feedback.
